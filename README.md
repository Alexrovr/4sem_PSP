## Описание функциональности

Калькулятор реализует полный набор базовых арифметических операций и дополнительные функции:

### Основные операции
- **Сложение (+)** — Суммирование двух чисел
- **Вычитание (-)** — Вычисление разности двух чисел
- **Умножение (×)** — Произведение двух чисел
- **Деление (/)** — Частное от деления

### Дополнительные функции
- **Смена знака (+/-)** — Изменение знака текущего числа
- **Процент (%)** — Вычисление процента от числа
- **Корень квадратный (√)** — Вычисление квадратного корня
- **Возведение в квадрат (x²)** — Возведение числа в степень 2
- **Факториал (x!)** — Вычисление факториала
- **Тройной ноль (000)** — Быстрое добавление нулей
- **Backspace** — Удаление последней введённой цифры
- **Очистка (C)** — Полная очистка калькулятора

### Логика работы
1. Пользователь вводит первое число по цифрам
2. Выбирает операцию
3. Вводит второе число
4. Нажимает "=" для получения результата
5. Результат сохраняется как новое первое число для цепочки операций

## Основные концепции JavaScript

### Переменные и типы данных
```javascript
let a = ''              // Строка для первого числа
let b = ''              // Строка для второго числа
let selectedOperation = null   // Выбранная операция
let expressionResult = ''      // Результат вычисления
```

### Получение элементов DOM
```javascript
// По ID (один элемент)
document.getElementById("result")

// По селектору (несколько элементов)
document.querySelectorAll('[id ^= "btn_digit_"]')
```

### Обработчики событий
```javascript
// Через свойство onclick
button.onclick = function() { }

// Через addEventListener (современный способ)
button.addEventListener('click', function() { })
```

### Функции
- **onDigitButtonClicked(digit)** — обработка нажатия цифр и точки
- **Обработчики операций** — для каждой операции своя функция
- **Вычисления** — использование switch для выбора операции

## Структура кода

### Инициализация (window.onload)
```
├── Объявление переменных (a, b, selectedOperation, expressionResult)
├── Получение доступа к элементам (outputElement, digitButtons)
├── Определение функции onDigitButtonClicked()
└── Настройка обработчиков событий
    ├── Цифровые кнопки (forEach для каждой кнопки)
    ├── Кнопки операций (+, -, ×, /)
    ├── Дополнительные операции (+/-, %, √, x², x!, 000, backspace)
    ├── Кнопка очистки (C)
    └── Кнопка равно (=)
```

### Основной алгоритм вычисления
```
1. Пользователь вводит цифры → составляется число a
2. Выбирается операция → selectedOperation = выбранная операция
3. Пользователь вводит цифры → составляется число b
4. Нажимается "=" → switch(selectedOperation) вычисляет результат
5. Результат сохраняется в a, b обнуляется
```

## Практические примеры

### Пример 1: Смена знака
```javascript
document.getElementById("btn_op_sign").onclick = function() {
    if (selectedOperation === null && a !== '') {
        a = String(Number(a) * -1);
        outputElement.innerHTML = a;
    } else if (selectedOperation !== null && b !== '') {
        b = String(Number(b) * -1);
        outputElement.innerHTML = b;
    }
}
```

### Пример 2: Вычисление процента
```javascript
document.getElementById("btn_op_percent").onclick = function() {
    if (selectedOperation === null && a !== '') {
        a = String(Number(a) / 100);
        outputElement.innerHTML = a;
    }
}
```

### Пример 3: Backspace
```javascript
backspaceButton.onclick = function() {
    if (selectedOperation === null) {
        a = a.slice(0, -1);
        outputElement.innerHTML = a || '0';
    } else {
        b = b.slice(0, -1);
        outputElement.innerHTML = b || '0';
    }
}
```
