## Описание стилистики

Дизайн проекта ориентирован на современный минимализм с акцентом на функциональность и удобство использования:

### Навигация
- Панель навигации расположена в верхней части страницы
- Активная вкладка подсвечивается
- Содержит ссылки на все основные страницы проекта
- Может быть закреплена при скролле (position: sticky)

### Калькулятор
- Белая карточка с тенью (box-shadow)
- Кнопки квадратной или близкой к квадратной формы со скруглением
- Дисплей с контрастным фоном и крупным шрифтом
- Кнопка "=" выделена отдельно, может быть другого цвета

### Страницы контента
- Информация организована в удобные блоки
- Используется единая цветовая схема
- Текст хорошо читаемый на выбранном фоне

### Главная страница
- Может содержать фоновое изображение (photo.jpg)
- Приветственное сообщение или информация о проекте

## Используемые технологии

- **HTML5** — семантическая разметка (header, nav, main, section)
- **CSS3** — flexbox, transitions, box-shadow, псевдоклассы :hover и :active
- **Шрифты** — семейство sans-serif для универсальности
- **Цветовая схема** — адаптивная под выбранный стиль
- **Изображения** — оптимизированные изображения (photo.jpg)

## Навигация между страницами

Проект содержит следующие основные страницы:

1. **calculator.html** — Основная страница с интерактивным калькулятором
2. **info.html** — Информационная страница
3. **dop.html** — Дополнительная страница

Все страницы объединены единой навигационной панелью с визуальным индикатором активной страницы. Это обеспечивает удобное перемещение между разделами проекта.

## Основные CSS-свойства

| Свойство | Назначение |
|---|---|
| `display: flex` | Гибкая раскладка элементов |
| `position: sticky` | Закрепление элементов при скролле |
| `box-shadow` | Тень для элементов и карточек |
| `transition` | Плавная анимация при наведении и смене состояния |
| `border-radius` | Скругление углов кнопок и контейнеров |
| `background-image` | Фоновое изображение на страницах |
| `user-select: none` | Запрет выделения текста на кнопках |
| `font-weight` | Жирность шрифта для акцентов |
| `font-size` | Размер шрифта для иерархии текста |
| `color` | Цвет текста и элементов |
| `background-color` | Цвет фона элементов |
